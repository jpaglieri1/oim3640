Project 1 Proposal

**What I'm building:** I am building the personal finance calculator, allowing the user to caluclate interest, payments, and the value of a loan.

**Why I am building this:** I chose this for two reasons. First, I think this would be helpful for me to be able to use for my current/future car payments, mortgage, and investments. Second, I think learning how to build this type of model will help me in the future, as I am going into the accounting and finance field.

**Core Features:**
- User can input information about the loan/investment (i.e. principal and length)
- The program will create an amortization table consisting of the beginning balance, payment, payment allocated to principle, payent allocation to interest, and ending balance.
- A user can also choose a compare feature that allows them to input information on multiple different loans/investments and compare them based on the calculations made in the model.

**What I don't know yet:** How I will be able to format the amortization table in a way that will be comprehendible to the user.
