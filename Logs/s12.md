During this sesssion, we went over lists and how they store data. Lists are mutable, unlike strings, meaning that they can be edited and changed after being created. There are several different functions that can be used to edit strings, such as append, remove, and pop. To do so, you would use the name of the list prior to .append, .remove, etc. (example: list.append("hi")).

Similar to strings, you can also return items at specific indexes of the list. For example:
    stocks = ['AAPL', 'GOOG', 'META', 'AMZN']
    stocks[1:3]
    >>> ['GOOG', 'META']

Also, to make a copy of a list, you use the same format but do not put any index positions (example: list[:]).
