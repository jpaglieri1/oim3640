In this lesson, we discussed iteration and touched upon for loops and while loops.

For loops are used to iterate through a set number of items, such as items in a list or characters in a string. The syntax is as follows:

    for letter in word:
        if letter = a:
            a_count += 1

While loops, on the other hand, continue iterating while a specific condition is met. For example:
    
    x = 10
    while x != 1
        x -= 1
        print(x)

In doing so, the program will print:
    8
    7
    6
    5
    4
    3
    2
    1
and then will stop interating.

The functions break and continue are alse useful; break will automatically stop the iteration without a specific condition being met, and continue will allow the user to continue going through the iteration.
