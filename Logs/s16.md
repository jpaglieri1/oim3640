Today I learned more about analyzing text files in python.

Using yfinanace, we were able to collect the data about different stocks and create a data dictionary using this information. I became more familiar with using tuples to create data dictionaries, specifically through extracting data from yfinance into the program.

I also learned about sets, which hold unique items only. Sets are unordered and mutable. To create them, the syntax is as follows:
    stocks = ['APPL', 'NVDA', 'APPL', 'GOOG']
    unique_stocks = set(stocks)
    
    print(unique_stocks)
    {'APPL', 'NVDA', 'GOOG'}

Sets look like datasets, however they are more similar to lists in that they are mutable and they are items that are separate by a comma, rather than associated with other data.

Using sets in data can be helpful because by removing repeated words, your code is able to run significantly faster. This can be helpful in my miniproject, as timing was a concern of mine.
