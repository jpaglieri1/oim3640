Today I learned about data dictionaries and how to manipulate data using it.

Data dictionaries and stored similar to lists and within that certain items are assigned with a corresponding item. For example, in a data dictionary where English words are translated to Spanish words, the wors would be stored as follows:
            {'one': 'uno', 'two': 'dos', 'three': 'tres', 'four': 'cuarto'}

To create an empty dictionary, it is created as follows:
            [name] = {}
So, for a dictionary called prices, it would be defined by;
            prices = {}
Then, to add values to the dictionary, you:
            prices['APPL'] = 178.5
            prices['GOOG'] = 141.8
            prices['MSFT'] = 405.63
To iterate through data in a data dictionary, a for loop can be used as well.
