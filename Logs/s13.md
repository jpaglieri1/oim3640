Today I learned about how to maniupulate lists, through operators such as:
- split --> This can create a list because on a string and split it using a certain item in the string.
        For example: the string "NVDA,META,GOOG,MSFA" split at "," would create a list containing the values "NVDA," "META," "GOOG," and "MSFA."
- strip --> this will remove a value at the first appearance of a string
        For example: if a string is "apple" and you are removing the letter "a", it would return "pple."
