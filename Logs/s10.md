In this session we learned about strings. One thing I had not realized previously were that strings are immuatable, meaning that they can not be changed. Therefore, in order to change a string, a new variable either needs to be created or the existing variable needs to be redefined with the adjustments included. For example:

    name = "Jackie"
    fullname = name + " Paglieri

You are not able to just do name + " Paglieri." However, you could do:

    name += " Paglieri"

Each character in a string is also given a specific position. So, if I wanted to print the first three letters in the word "Python," I would write the following:

    name = "python"
    name[0:3]
    >>> 'pyt'

Python can also analyze text files by trying to find specific strings in the file, through iteration. You can also edit the file using python functions, such as replace, like this:

    writer = open('pg345_replaced.txt', 'w')

    for line in open('pg345_cleaned.txt'):
      line = line.replace('Jonathan', 'Thomas')
        writer.write(line)
