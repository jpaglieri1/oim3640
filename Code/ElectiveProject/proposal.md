Project 1 Proposal

**What I'm building:** I am building an agenda builder where the user is able to create an agenda and insert tasks to organize.

**Why I am building this:** I chose this because I have been using excel to organize the tasks I have to complete and I wanted a way to sort it by due date without doing it manually every time I add an assignment, so I elected to try to code it.

**Core Features:**
- User can choose specific formats or create their own
- User can create multiple different agendas (school, work, person, etc.)
- User can add tasks, due date, % completion, and other informaiton about a task


**What I don't know yet:** If there is a way to save the information so that the user does not need to input the data every time they close the application.
