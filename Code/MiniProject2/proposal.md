## My Project Proposal

**What I'm building:** I am building an platform for employers to input a candidates resume and analyze how well they fit a job description based on keywords.
**Why I chose this:** I chose this because I think it would be interesting to see a practical and applicable way in which python coding could be used for this type of analysis, especially since many companies are starting to use AI to screen resumes.
**Core features:**
- The user will be able to input a job description and some keywords they are looking for in someone's resume.
- The user can continue inputting multiple resumes into the program, thus allowing them to be able to compare the candidates.
- The program will display what keywords appeared in the candidates resume, and give them a score based on that.
- The keywords that are missing from a candidates resume will also be displayed. 
**What I don't know yet:**
- How I will come up with a system that will provide a rating to each candidate
- How uppercase and lowercase will affect the results and how to combat this.
- If the program runs through every word in a job description, will the program take too long?
