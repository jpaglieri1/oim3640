This project serves as a user's personal finanacial calculator, with the added benefit of it being able to show you an amortization table as well. This is not only useful to students, trying to complete their FIN2000 homework or calculate their summer housing payments, but also to professionals looking for a quick way to make a caluclation, right from their computer.

**How the program works**
The user will first be prompted to input the data available about the loan or investment. The following information will be requested, though not all are required:

1. Present value
2. Future value
3. Interest rate (annually)
4. Payment amount
5. Length of loan or investment
6. The number of times interest is compounded per year

NOTE: the interest rate will be converted automatically to the effective rate; perpetuities can not be inputted into this application.

**Features**
1. Calculator:
The program will calculate an information that was not inputted and will display the inputted and calculated information, however, the calculated data will not be stored.
2. Amortization Table:
This feature will develop an amotization table using the information inputted. For any missing information, the program will solve for that data and then create the table.
3. Input new data:
This allows the user to add another set of data, giving them the ability to compare loans and invetsments or analyze multiple investing options. When this option is chosen, the previously entered data will only be cleared if the user enters, '0.' Otherwise the initially inputted data will remain stored with the newly inputted data.
4. Exit
This will close the application.
